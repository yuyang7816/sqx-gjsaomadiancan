# 商家端运行教程

按顺序做。这是门店店员用的手机应用，用来看今天赚了多少、处理订单、上下架菜品、管理桌位。顾客点餐不用这个应用。

代码在 `saomadiancan-gj-shop`。用 HBuilderX 打开。中文下首页标题是「点餐门店端」。底部三个图标是：**首页、订单、我的**。

先按 [服务端运行教程](服务端-运行教程.md) 启动服务端。要看本机门店时，把接口改到本机。地址还是线上时，打开的是线上门店的数字。

## 第 1 步：改接口地址

用记事本打开：

```text
saomadiancan-gj-shop/common/config.js
```

现在四行地址是：

```text
https://dcgjsh.xianmxkj.com/sqx_fast
```

连本机服务端时，四行都改成：

```text
http://127.0.0.1:8878/sqx_fast
```

保存。手机真机预览时，同样要把 `127.0.0.1` 换成电脑的局域网 IP，手机和电脑在同一个 Wi-Fi。

用户端和商家端各有一份 `config.js`，改了一个不会带动另一个。两边都要连本机时，两个文件都改。

## 第 2 步：用 HBuilderX 打开

1. 「文件」→「打开目录」。
2. 选中 `saomadiancan-gj-shop` 这个文件夹。

不要选仓库根目录，也不要选成 `saomadiancan-gj-user`。两个都是 uni-app 项目，选错文件夹时，跑起来的是顾客端，不是门店端。

打开正确时，左侧能看到 `pages/index`、`pages/order`、`pages/loginphone`、`pages.json`。

## 第 3 步：运行

菜单选「运行」→「运行到浏览器」→ Chrome。

打开后应能看到：

- 顶部标题「点餐门店端」
- 没登录时，头像旁边是「登录」
- 三块数字：本年收益、今日收益、本月收益。还没登录或没有订单时，这些数是 0
- 下面还有收银台、我的订单（制作中、待取餐、已完成、已取消）、我的商品（上架中、已下架、添加商品）

能看到这些格子，说明页面已经编译出来。数字如果一直不出来、整页白屏，先看服务端是否还开着，以及第 1 步的地址是否保存。

## 第 4 步：登录门店账号

首页点「登录」，进入门店管理员登录。要填：

1. 账号
2. 密码
3. 图片验证码（点图片可以换一张）
4. 勾选隐私协议和用户协议

这是**门店账号**，不是管理后台的 `admin`，也不是顾客用邮箱注册的那个账号。门店账号在管理端「门店中心」里维护。还没有门店、也没有店员账号时，这里登录不会成功。先到管理端建好门店和管理员，再回来登录。

登录成功后，首页店名不再是「登录」，收益和订单数字改为这家店自己的数据。

## 第 5 步：微信小程序（可选）

1. 打开 `saomadiancan-gj-shop/manifest.json`。
2. 把 `mp-weixin` 里的 `appid` 换成你自己的小程序 AppId。商家端和用户端是两个小程序，AppId 各用各的。
3. HBuilderX 里运行到微信开发者工具。

管理端「系统配置」里还有「门店端小程序 AppId」和「门店端小程序密钥」。那是服务端调用微信时用的，和 `manifest.json` 里的 AppId 要一致，否则手机号授权、支付会失败。

## 打不开时

**跑起来发现是顾客的「点餐」首页，不是「点餐门店端」。**  
HBuilderX 打开错了文件夹，打开的是 `saomadiancan-gj-user`。关掉项目，重新打开 `saomadiancan-gj-shop`。

**登录验证码不显示。**  
服务端没启动，或 `config.js` 的地址不通。先看服务端窗口，再确认地址是 `http://127.0.0.1:8878/sqx_fast`。

**账号密码确定没错，仍提示失败。**  
验证码错了，或这个账号不是这家店的管理员。到管理端核对门店管理员，不要用 `admin` 来登商家端。
