# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。顾客点餐、店员接单，都不打开这个网站。

程序名称是「省钱兄国际扫码点餐系统」。代码在 `saomadiancan-gj-admin` 文件夹。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入，并让服务端窗口保持打开。窗口里要已经出现「外卖点餐项目启动成功」。服务端没开时，这个网站也能打开，但验证码图片是裂的，登录会失败。

## 第 1 步：安装 Node.js

管理端要求 **Node.js 18.13 或更高**。到 Node.js 官网安装后，新开一个 PowerShell，输入：

```bash
node -v
npm -v
```

`node -v` 应显示 `v18` 或更高。版本太低时，先升级再继续。升级之后要重新打开 PowerShell。

## 第 2 步：把接口改到本机

用记事本或 VS Code 打开：

```text
saomadiancan-gj-admin/config/index.js
```

在文件前部能找到一段 `proxyTable`，里面有 `/sqx_fast`。本机联调时，把 `target` 改成：

```text
http://127.0.0.1:8878/sqx_fast/
```

`pathRewrite` 那一行保持不动，它的作用是把页面请求转到上面这个地址。

文件里如果还写着线上管理端域名，页面会去连线上，你在本机导入的门店和商品都不会出现。改完一定要保存。

## 第 3 步：安装依赖

仓库里不带 `node_modules`，第一次必须自己安装。

1. 打开 `saomadiancan-gj-admin` 文件夹。
2. 在空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」。
3. 输入：

```bash
npm install
```

等到命令自己结束、出现新的输入提示，才算装完。中途不要关窗口。这一步只在第一次，或依赖有变动时再做。以后日常启动不用重复安装。

如果这里报网络错误，多半是公司网络拦了下载。换一个网络，或稍后再执行一次 `npm install`。

## 第 4 步：启动网站

还是在 `saomadiancan-gj-admin` 这个窗口里执行：

```bash
npm run dev
```

启动成功时，浏览器通常会自己打开。默认地址是：

```text
http://127.0.0.1:8001
```

8001 被别的程序占用时，窗口里会打印实际用的端口，以窗口里那一行为准。

这个窗口也要保持打开。关掉它，浏览器里的后台就没了。它和服务端是两个窗口，两个都要开着。

如果启动时报 `digital envelope` 或 OpenSSL 相关错误，在同一个窗口先执行下面这一行，再重新执行 `npm run dev`：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
```

## 第 5 步：登录

打开的页面标题一带写着「省钱兄国际扫码点餐系统」，右侧是登录框。要填三项：

1. **账号**
2. **密码**
3. **验证码**（右边有一张图片，看不清就点图片换一张）

导入数据库之后，账号是 `admin`。密码是脚本写进 `sys_user` 表里的那个，页面上看不到明文，它也不是 MySQL 的 root 密码。验证码必须按图片上的字符填写，区分不清时点图片刷新再试。

登录成功后，左侧出现菜单，第一页是「数据概览」。能看到用户数、收入、订单这些数字（刚导入时很多是 0），说明管理端已经连上你本机的服务端。

## 打不开或登录失败时

**验证码图片是裂的，或一直转圈。**  
服务端窗口不在了，或第 2 步的地址没改对。先确认服务端还有「外卖点餐项目启动成功」，再确认 `config/index.js` 里是 `127.0.0.1:8878`，保存后重新执行 `npm run dev`。

**提示账号或密码错误。**  
账号先确认是 `admin`。密码不要填 MySQL 的 root 密码。验证码过期时也会登录失败，点图片换一张再提交。

**页面能开，但列表永远是空的，和你导入的数据对不上。**  
接口还指向线上。回到第 2 步改 `target`，保存后重启 `npm run dev`。

**`npm` 找不到。**  
Node.js 没装好，或装完后没有重新开 PowerShell。

登录看到数据概览之后，再去运行 [用户端](用户端-运行教程.md) 和 [商家端](商家端-运行教程.md)。
