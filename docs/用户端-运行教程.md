# 用户端运行教程

按顺序做。这是顾客扫码点餐用的手机应用，也可以先在电脑浏览器里看。窗口在中文下标题是「点餐」。底部四个图标是：**首页、下单、订单、我的**。

代码在 `saomadiancan-gj-user`。用 HBuilderX 打开这个文件夹来运行，不是用 `npm run dev`。

先按 [服务端运行教程](服务端-运行教程.md) 导入数据库并启动服务端。要看自己电脑里的门店时，还要把下面第 1 步的地址改到本机。地址仍指向线上时，页面也许能打开，但看到的是线上那一套门店，和你本机后台对不上。

## 第 1 步：改接口地址

用记事本打开：

```text
saomadiancan-gj-user/common/config.js
```

文件最上面有四行地址，现在写的是：

```text
https://dcgj.xianmxkj.com/sqx_fast
```

这是线上演示。你要连自己刚启动的服务端时，四行都改成：

```text
http://127.0.0.1:8878/sqx_fast
```

保存。

只在自己电脑的浏览器里看，用 `127.0.0.1` 就可以。要用手机扫码看本机时，`127.0.0.1` 代表的是手机自己，不是你的电脑。这时把 `127.0.0.1` 换成电脑的局域网 IP，例如 `http://192.168.1.20:8878/sqx_fast`，手机和电脑要连同一个 Wi-Fi。电脑 IP 可在 PowerShell 里输入 `ipconfig` 查看。

## 第 2 步：用 HBuilderX 打开项目

1. 安装 HBuilderX 正式版，并打开它。
2. 菜单选「文件」→「打开目录」。
3. 选中 `saomadiancan-gj-user` 这个文件夹。

不要选它的上一级。上一级还有服务端、管理端、商家端，HBuilderX 认不出来。也不要只打开里面某一个页面文件。

打开正确时，左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`。

## 第 3 步：运行到浏览器

1. 菜单选「运行」→「运行到浏览器」→ Chrome（或你安装的浏览器）。
2. 第一次运行，HBuilderX 可能要下载编译器，等它自己完成。
3. 浏览器打开后，底部应能看到四个图标。点第一个，标题是「点餐」，页面上有「每日任务」「积分商城」。

H5 开发端口写在 `manifest.json` 里，当前是 **8080**。如果 8080 被占用，HBuilderX 控制台会提示实际端口。

服务端地址仍是线上时，你看到的是线上数据，这不算连上了本机。要确认本机是否接通，看第 1 步是不是已经改成 `127.0.0.1:8878`，并且服务端窗口还开着。

## 第 4 步：怎样算跑通

按这个顺序点一遍：

1. **首页**能出来，不是一直白屏。有任务卡片或轮播，说明接口有返回。
2. 点底部第二个图标进入**下单**。浏览器如果询问定位，选允许。允许后应出现附近门店；定位失败时，页面会停在选店，需要你稍后在手机或允许定位的浏览器里再试。
3. 点进一家门店，能看到店名，以及「自取」「外卖」两个切换。店里还没有上架商品时，中间是空的，这是数据为空，不是程序没编译成功。
4. 点「我的」，能看到登录、优惠券、钱包、积分。点「登录」能看到「邮箱登录」和「手机号登录」。

商品要从管理端或商家端先加好、并上架，下单页才会有菜。

## 第 5 步：运行到微信小程序（可选）

要用微信里预览时：

1. 安装微信开发者工具。
2. 打开 `saomadiancan-gj-user/manifest.json`，把 `mp-weixin` 里的 `appid` 换成你自己的小程序 AppId。
3. 在 HBuilderX 里选「运行」→「运行到小程序模拟器」→ 微信开发者工具。

AppId 还是项目里原来的那一个时，只能在你自己有权限的账号下预览，换一台没有权限的电脑会报 AppId 错误。

短信、微信支付、支付宝、PayPal、Stripe、地图这些，要另外申请账号，并填到管理端「系统配置」里。只把用户端跑起来，不会自动拥有这些服务。填在哪里、不填会怎样，见 [用户端功能说明](用户端-功能说明.md) 最后一节。

## 页面打不开时

**HBuilderX 里找不到运行到浏览器。**  
确认打开的是整个 `saomadiancan-gj-user` 文件夹，不是单个 vue 文件。

**浏览器一直白屏。**  
看 HBuilderX 下方控制台有没有红色报错。第一次运行时先等编译结束。公司网络拦截编译器下载时，换网络再运行一次。

**首页能开，一点下单就没有门店。**  
浏览器没允许定位，或服务端没启动，或 `config.js` 仍指向一个没有数据的地址。先看服务端窗口是否还在，再允许定位后刷新。

**改了 config.js 却还是线上的店。**  
文件没保存，或 HBuilderX 用的是改之前的编译结果。保存后停止运行，再点一次「运行到浏览器」。
