# 用户端功能说明

用户端是顾客扫码点餐时，在手机或电脑网页里打开的那个应用。中文下窗口标题是「点餐」。底部一直有四个图标：**首页、下单、订单、我的**。图标上的字来自多语言配置，切换语言后会变。

门店店员不使用这个应用来接单，他们用商家端。上架全平台的菜、填写支付密钥，在电脑上的管理端做。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、PayPal、短信这些外面的服务。

## 这个端是给谁用的

- **顾客**：选门店，看菜单，自取、外卖或到店堂食，付款，看订单，用会员、优惠券、钱包和积分。
- **还没登录的人**：可以浏览首页，也可以看门店和商品。一点去结算、看钱包、领券、做任务，就会提示先登录。

没有单独再装一个「平台员工 App」。退款、改配置在管理端完成，做菜和出餐在商家端完成，顾客在这里看进度。

## 首页

打开就是首页，标题是「点餐」。

- **轮播图**：后台「首页装修」里配置的广告。点某一张，会按后台设置跳转。库里没配图时，这一块是空的，下面的内容仍在。
- **每日任务**：例如每日签到拿积分。没登录会先去登录。签到给多少分，由管理端系统配置决定。导入后是开启签到，每天 10 分。
- **积分商城**：用积分兑换。旁边的说明是积分商城兑好礼。
- **我的积分**：进入积分，可以看积分兑换优惠券一类入口。

从扫码或链接进来时，如果地址里带了这家店的 `shopId`，首页不会停住，会直接切到这家店的下单页。微信小程序码里的场景值也是这个作用：先认出是哪一家店，再打开菜单。

下拉可以刷新。这些内容来自你导入的数据库，或你在管理端改过的数据。服务端没启动时，这里会一直转圈或是空的。地址仍指向线上时，看到的是线上数据，不是你本机后台刚改的那一条。

## 下单

底部第二个图标。

### 先选店

允许定位后，按距离列出附近门店。每一家能看到店名、距离、地址、营业时间。上面可以搜店名。

浏览器或手机如果询问定位，点允许。定位失败时，附近列表出不来，需要换一个能定位的环境，或从带 `shopId` 的链接直接进店。

点某一家店才进入菜单。这家店在后台被下架时，打不开正常点餐。

### 进店之后

- 顶部是这家店的横幅。没配图时，横幅是空的。
- 店名可以点，返回再选别的店。
- **自取** 和 **外卖** 两个切换。自取是到店取，外卖是送到地址。
- 店名下面有距离。
- 左边是分类，右边是这个分类下的菜：图片、名字、简介、价格，右边有加号。
- 点加号如果这道菜有规格（大小、甜度这一类），会弹出规格，选完再加入。
- 底部是购物车：件数、金额，以及「去结算」。一件都没加时，点结算会提示先加商品。
- 这家店还没有上架商品时，中间是「暂无数据」。先到管理端或商家端把菜上架。

只看菜和价格，不需要微信或 PayPal。点去结算时才要登录。

## 确认订单和付钱

从购物车点「去结算」后进入确认。

- **外卖**要有收货人、电话、详细地址。没有地址时先去新增。
- **自取**看取餐号和门店，不用填上门地址。
- 能看到菜品、规格、备注、打包费、外卖跑腿费、优惠券、会员折扣，以及实付。
- 跑腿费、满多少免配送费、会员几折，都是管理端系统配置里的数字。导入后跑腿费是 0，满 20 免配送费，会员折扣是 0.9。
- 有可用优惠券时可以选择。没有券，或金额没到门槛，会提示暂无或不满足条件。

再选怎么付钱。当前环境用不到的方式，点下去不会真的付成：

- **钱包余额**：扣「我的钱包」里的钱，不经过微信或 PayPal。余额是 0 就不能付成功。
- **微信支付**：在微信里拉起微信支付。要管理端已经填了小程序或公众号，以及商户号。
- **支付宝**：拉起支付宝。要开放平台的应用已经配好。
- **PayPal**：跳到 PayPal 的页面支付。适合海外顾客。开关和密钥在系统配置里。导入后开关是开的，密钥是空的，所以还付不了。
- **Stripe**：跳到 Stripe 的页面支付。同样要公钥、秘钥和回调签名。导入后开关是开的，密钥是空的。

付成功后，支付公司会通知服务端，订单才会变成已支付。付完立刻关页面、通知还没到时，订单可能要等一会儿才变。没付完的，可以在订单里再付。

## 订单

底部「订单」。标题是订单中心。最上面三类：

- **到店取餐**
- **外卖配送**
- **到店堂食**

到店取餐下面还可以筛：**全部、制作中、待取餐、已完成、已取消**。  
外卖配送下面可以筛：**全部、制作中、已完成、已取消**。

没下过单时，中间是一个空状态，写着「暂无数据」。

点进某一单，能看到：

- 当前状态，例如制作中、待取餐、配送中、已完成、已取消
- 取餐号，以及前面还有多少单在排队（有这个数据时才显示）
- 菜品、规格、单品备注
- 打包费、跑腿费、优惠券减免、会员折扣、实付
- 收货人、电话、详细地址（外卖才有）
- 下单时间、订单编号。订单编号旁边可以复制
- 支付方式。用余额付的，这里显示零钱
- 整单备注

外卖且状态是配送中时，列表上有「确认收货」。点下去是告诉服务端这单顾客已经收到。

退款不是顾客在这里点一下就到账。店员或平台在商家端、管理端处理之后，状态才会变。

## 我的

底部「我的」。没登录时顶部是「登录」，右边有一个地球图标，用来切换语言。

语言列表来自管理端「语种配置」。默认语言是中文。切换之后，按钮和菜名会按那种语言重新取。某种语言的词还没配时，对应的字会空着或仍是原文。

登录页有两个按钮：

- **邮箱登录**
- **手机号登录**

手机号登录可以选国家区号。注册时填写姓名、手机或邮箱、验证码、密码，邀请码可以不填。登录前要勾选《隐私协议》和《用户协议》，正文是管理端系统配置里写的那一份。

邮箱验证码要系统配置里的网易邮箱账号和授权码。短信验证码要短信服务商的账号。刚导入时这两边的账号是空的，所以验证码发不出去。怎么改，见本文最后一节。

登录后，头像下面常见这些入口。名字以你屏幕上的为准：

- **优惠券、我的钱包、我的积分**：三个数字，点进去是对应的列表。
- **超级会员享福利**：还没开通时按钮是「去开通」，开通后显示已开通。开通要按会员配置的价格付款。
- **每日任务**：每日签到领积分。
- **积分商城**：积分兑换优惠券。
- **推荐工具**
  - 分享好友：按后台的推广图片和推广文案生成分享。导入后的文案是「快来加入我们吧」。
  - 钱包明细：每一笔充值、消费。
  - 任务中心
  - 联系客服：常见问题和在线客服。客服微信、客服二维码空着时，这里没有联系方式。在线客服要有人在管理端回复。
  - 消息中心：站内通知。这不是手机短信。
  - 地址管理：新增、编辑外卖地址。
  - 系统设置：协议、退出登录一类。

钱包充值若选微信、PayPal 或 Stripe，同样要密钥。可选金额默认有 10、100、200、500。

## 这个端真正会连到外面的服务

短信、微信、支付宝、PayPal、Stripe、地图、邮箱的密钥填在管理端「系统配置」，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 填在哪里 | 没填或还是默认时 |
|---|---|---|---|
| 邮箱注册、邮箱登录收验证码 | 网易 163 邮箱的 SMTP 授权码 | 管理端「系统配置」里的发件邮箱、端口、授权码 | 邮箱收不到验证码 |
| 手机号收验证码 | 短信宝、阿里云短信或腾讯云短信，三家里开通一家 | 把短信服务商改成 3、2 或 1，并填写对应账号 | 导入后是短信宝，但用户名是空的，手机收不到 |
| 微信支付 | 微信支付商户号，还要小程序或公众号 AppId | 管理端「系统配置」 | 无法拉起微信支付 |
| 支付宝付款 | 支付宝开放平台的应用和密钥 | 管理端「系统配置」里支付宝那几项（页面上有才填） | 无法拉起支付宝 |
| PayPal | PayPal 的 clientId、密钥，并选择 sandbox 或 live | 管理端「系统配置」 | 开关虽然是「是」，密钥是空的，付不了 |
| Stripe | Stripe 公钥、秘钥、回调签名 | 管理端「系统配置」 | 同样是开关开着、密钥为空，付不了 |
| 小程序登录 | 微信小程序 AppId 和秘钥 | 管理端「系统配置」，同时把 `manifest.json` 里的 AppId 换成你自己的 | 授权失败 |
| 地图上选地址 | 腾讯地图 key。H5 工程里还预留了 Google 地图 | 管理端「系统配置」，Google 的 key 在用户端 `manifest.json` | 地图选点失败。详细地址仍可以手填 |
| 把头像、菜品图存到阿里云 | 阿里云对象存储 | 把上传方式从 `2` 改成 `1` 并填写密钥 | 不改也可以。默认存在运行服务端的那台电脑上 |

短信三家只用开通其中一家。图片不申请阿里云也能先存在本机。

下面这些不用申请外面的 Key，服务端和数据库就绪就能用：

- 浏览库里已经有的门店、轮播、分类和商品。
- 把地址、购物车存进自己的数据库。
- 用钱包余额付款。余额是 0 时，其他支付方式仍要上面的密钥。
- 领券、看订单、给客服发消息。这些都记在自己的库里。

下面这些看起来像外面的服务，但当前不会真的连出去：

- 复制订单号：只是复制文字。
- 在线客服：连自己的服务器，不是企业微信。要有人在管理端回复。
- 分享好友：用的是后台保存的图片和文案，不是自动发到微信朋友圈。
