# 服务端运行教程

按顺序做。先把这一端跑起来，再去开管理端、用户端、商家端。

服务端没有给人点的页面。它是一台一直开着的程序：手机上的点餐页面、门店页面，以及电脑上的管理后台，都把登录、看菜、下单、付款这些请求发给它。它负责检查能不能做这件事，并把结果记进数据库。

代码在 `saomadiancan-gj-service` 文件夹。启动之后，窗口里会出现「外卖点餐项目启动成功」。这个窗口要一直开着，关掉之后另外三端就连不上数据。

## 开始之前

你的电脑上需要这三样软件。都装好之后，再做后面的步骤。

| 软件 | 要用的版本 | 怎么确认已经装好 |
|---|---|---|
| JDK | **8**（也叫 1.8） | 打开 PowerShell，输入 `java -version`，结果里要能看到 `1.8` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能打出一段版本说明 |
| MySQL | 8.0 或更高 | 能用 Navicat、小皮面板，或 MySQL 自带的命令行连上本机 |

`java -version` 如果显示的是 11、17 或更高，先改成 JDK 8 再继续。这个服务端按 Java 8 来编译。

本地默认**不使用 Redis**。配置里这项是关着的，第一次运行不用另外安装 Redis。

## 第 1 步：新建数据库

1. 打开你平时用来管 MySQL 的软件（Navicat、小皮面板、MySQL Workbench 都可以）。
2. 新建一个数据库，名字必须是：

```text
diancan4.0-gj
```

3. 字符集选 `utf8mb4`。排序规则如果要你选，选带 `utf8mb4` 的那一项即可。

名字要一模一样，中间的点也要保留。名字不对时，后面启动会报找不到数据库。

## 第 2 步：导入数据脚本

脚本文件在：

```text
saomadiancan-gj-service/db/diancan4.0-gj.sql
```

这个文件只建表、写入菜单和配置，**不会自己创建数据库**。所以必须先做完第 1 步。

用 Navicat 时：

1. 双击打开刚建的 `diancan4.0-gj`。
2. 右键这个库，选「运行 SQL 文件」或「执行 SQL 文件」。
3. 选中上面的 `diancan4.0-gj.sql`，执行到结束。
4. 执行过程中如果停在红色报错，把第一行报错留下来，不要继续猜。

导入成功后，在这个库里应能看到这些表：`goods`（商品）、`tb_order`（订单）、`sys_user`（后台管理员）、`language_type`（语言）。一张都没有，就是没导入进这个库。

## 第 3 步：把数据库地址改成本机

用记事本或 VS Code 打开这两个文件。

第一个：

```text
saomadiancan-gj-service/src/main/resources/application.yml
```

找到 `spring.profiles.active`，保持为：

```text
prod
```

第二个才是数据库账号，在：

```text
saomadiancan-gj-service/src/main/resources/application-prod.yml
```

找到 `url`、`username`、`password`。本机运行时改成你自己的 MySQL，例如：

```yaml
url: jdbc:mysql://127.0.0.1:3306/diancan4.0-gj?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=CTT
username: root
password: 你的MySQL密码
```

注意这几件事：

- 地址用 `127.0.0.1`，端口一般是 `3306`。
- 库名保持 `diancan4.0-gj`，不要改成别的。
- `username` 和 `password` 是 MySQL 的登录账号，不是后面管理后台的 `admin`。
- 文件里如果原来写的是一台远程服务器，页面会去读远程库，看不到你刚导入的数据。本机练习时改到 `127.0.0.1`。
- 改完保存。没保存就启动，用的还是旧地址。

同一份文件里有一段被 `#` 注释掉的本机示例，用户名是 `root`，密码示例是 `123456`。那只是示例。你的 MySQL 密码是什么，就填什么。

## 第 4 步：启动

1. 打开 `saomadiancan-gj-service` 这个文件夹。
2. 在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」。
3. 输入下面这一行，回车：

```bash
mvn spring-boot:run
```

第一次会下载很多依赖，窗口会连续滚动，可能要几分钟。这是正常的。不要在它还在滚动时把窗口关掉。

出现下面这句，才算启动成功：

```text
外卖点餐项目启动成功
```

成功之后记住两个地址：

| 项目 | 值 |
|---|---|
| 端口 | **8878** |
| 所有接口前面的路径 | **`/sqx_fast`** |

用浏览器打开：

```text
http://127.0.0.1:8878/sqx_fast/swagger-ui.html
```

能看到一页接口列表（商品、订单、支付这些分组），说明程序已经连上数据库。这一页是给排查接口用的，顾客不用打开它。

## 第 5 步：确认管理员账号还在

导入成功后，后台管理员账号是 `admin`。密码保存在表 `sys_user` 里，而且是加密的，用记事本打开 SQL 文件看不到明文密码。

这个密码和 MySQL 的 `root` 密码不是同一个。管理端登录时再用它。登录还要填一张图片验证码。

## 启动失败时先看哪里

按你看到的现象对一下。

**输入 `mvn` 提示找不到命令。**  
Maven 没装好，或没加到系统路径。装好之后重新打开一个 PowerShell 再试。旧窗口不会自动认识新安装的软件。

**`java -version` 不是 1.8。**  
先改成 JDK 8。版本不对时，编译会在中途报错停下。

**报错里有 Access denied 或 Communications link failure。**  
数据库账号、密码、端口不对，或 MySQL 没启动。回到第 3 步核对 `application-prod.yml`，并确认 MySQL 服务是开着的。

**报错里有 Unknown database。**  
库还没建，或库名不是 `diancan4.0-gj`。回到第 1 步。

**窗口一闪就关了。**  
不要双击某个 bat 去启动。用第 4 步的 PowerShell，报错会留在窗口里。

**接口文档打不开。**  
先看 PowerShell 里有没有「外卖点餐项目启动成功」。没有这句，就还没启动完，或已经报错退出。地址必须带 `/sqx_fast`，只打开 `http://127.0.0.1:8878` 看不到文档。

服务端这个窗口从现在起不要关。接下来去看 [管理端运行教程](管理端-运行教程.md)。
